Customer Shopping Behavior Analysis

📊 Project Overview

This project analyzes customer shopping behavior using Microsoft Power BI and Excel. The dashboard provides insights into customer demographics, purchasing patterns, product categories, discounts and promotional offers, payment methods, and sales trends.

🎯 Objectives

- Analyze customer purchasing behavior
- Understand demographic patterns
- Identify top-performing product categories
- Analyze the impact of discounts and promotional codes
- Compare purchasing behavior across age and gender groups
- Analyze payment method preferences
- Identify seasonal and purchasing trends
- Present key findings through an interactive Power BI dashboard

🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

📂 Dataset

The project uses a customer shopping behavior dataset containing information related to customer demographics, purchases, product categories, discounts, payment methods, and purchasing patterns.
